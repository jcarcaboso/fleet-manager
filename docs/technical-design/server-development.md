# Run the development server

The Server is a .NET 10 process backed by PostgreSQL. The `fleet` Rust binary
administers it. Managed Agents and local Target reconciliation are not included
yet. The current Agent routes support a fake Agent for testing the Server.

Install .NET SDK 10.0.302, a Rust 2024 toolchain, Git, Docker with Compose,
OpenSSL, Python 3, and Make. Run from the repository root:

```sh
make restore
bash scripts/dev-setup.sh
source .local/dev.env
docker compose up -d --wait
dotnet run --project server/Fleet.Server -- --migrate
dotnet run --project server/Fleet.Server
```

In a second terminal, load the same environment and use the CLI:

```sh
source .local/dev.env
cargo run --manifest-path clients/Cargo.toml --bin fleet -- --ca-cert .local/issuer.pem nodes list
cargo run --manifest-path clients/Cargo.toml --bin fleet -- --ca-cert .local/issuer.pem enrollment create
```

Enrollment prints the new secret once to standard output. Treat redirected
output as a credential. The Server stores its digest and never logs its value.
The CLI reads the Operator token from the environment. The local setup stores
that token and private keys under `.local` with user-only permissions. It does
not overwrite an existing configuration.

`docker compose stop` stops the local database while retaining its volume.
The Compose password and loopback port are for development only.

## Source configuration

Prepare a separate Git repository from [the example](../../examples/source/README.md).
Enroll Nodes first, then replace its example Node aliases with their exact
enrollment names and commit to `main`.
Set the following before starting the Server:

```sh
export Source__Remote=/absolute/path/to/source-repository
export Source__MirrorPath="$PWD/.local/source.git"
```

The Server scans on startup and every 1,800 seconds. `Source__PollIntervalSeconds`
changes that interval. An Operator can request an immediate scan with
`fleet source rescan`. The source remote is administrator configuration, and
its credentials must have read access only. Never put credentials in its URL.

## Configuration and trust

Required settings use the environment names generated by `dev-setup.sh`.
`Fleet__WorkspaceId` is stable for the lifetime of the database.
`Fleet__OperatorTokenSha256` is the lowercase SHA-256 digest of an Operator token
containing at least 32 characters. Rotate the token by replacing the digest and
restarting the process. The configured Operator has full administrative access.

Kestrel terminates TLS directly and optionally requests a client certificate.
Every Node operation requires that certificate, a chain to the configured issuer,
and a current credential record. Proxy certificate headers are not trusted.
Operator routes require their bearer token and do not accept Node certificates.

## Node aliases

The enrollment request's `nodeName` is the Node alias. It is unique within the
Workspace, case-sensitive, nonblank, and at most 200 characters. Use simple names
such as `homelab-mini`. `fleet nodes list` exposes it as `name`. Source manifests
use that exact name as the key under `nodes`, without an `id` field.

An enrolled Node can change its own alias using its active client certificate:

```sh
curl --cacert ca.pem --cert node.pem --key node.key \
  --request PUT https://fleet.home.arpa:7443/agent/v1/alias \
  --header 'Content-Type: application/json' \
  --data '{"alias":"homelab-mini"}'
```

The response contains `nodeId` and `alias`. An occupied alias returns HTTP 409
with `node_alias_in_use`; invalid input returns HTTP 400. Repeating the current
alias succeeds without creating another audit event. Credentials and existing
Assignments remain attached to the same Node ID. Revoked credentials cannot
rename a Node, and an Operator bearer token cannot call this Node endpoint.

After renaming, update the key in `fleet.yml`, commit it, and run
`fleet source rescan`. The old alias becomes available again, so update the
source before assigning it to another Node. A revoked Node's current alias stays
reserved. Operators can rename a Node using their bearer token with
`fleet nodes rename <current-alias> <new-alias>`. The CLI calls the separate
Operator endpoint and does not need a Node certificate. See the
[Operator protocol](operator-protocol.md) for errors and retry behavior.

Use explicit HTTPS listening addresses and a Server certificate valid for the
configured hostname. The example certificate is valid for localhost only. The
issuing private key stays outside PostgreSQL and must have user-only permissions.
The POC supports a local network or an Operator-managed private overlay.

The following defaults are implementation choices pending measured budgets:

| Setting | Default |
|---|---|
| Node certificate lifetime | 7 days, configurable from 1 to 30 |
| Enrollment token lifetime | 900 seconds, request range 60 to 3,600 |
| Enrollment response retry window | 120 seconds |
| Recommended Agent poll delay | 60 seconds |
| Freshness threshold | 300 seconds |
| HTTP request body | 16 KiB |
| Concurrent HTTP requests | 128, no waiting queue |
| Enrollment and renewal requests per source address | 20 per minute |
| Database command timeout | 15 seconds |
| Collection page size | 100, maximum 200 |

`Fleet__AllowLoopbackHttp=true` allows development Operator/enrollment requests
from loopback over HTTP. Node operations still require HTTPS. Do not use that
option on a shared deployment.

## Migrations and checks

Apply migrations with `--migrate` before starting the host. Normal startup never
changes the database schema. Readiness fails until the schema can be queried.
Review generated migration SQL before applying it to retained data.

```sh
make format
make check
make test
make docs-check
dotnet list Fleet.slnx package --vulnerable --include-transitive
```

Tests create disposable PostgreSQL containers. They must fail when Docker is
unavailable. They do not substitute an in-memory database.

With the local HTTPS Server running and `.local/dev.env` loaded, run
`python3 scripts/smoke-https.py`. It uses real TLS to exercise enrollment, exact
response retry, mTLS polling, renewal, and revocation. It creates one test Node
and revokes it before returning. Test private keys stay in a temporary directory
and are deleted when the script finishes.

Liveness is `/health/live`; readiness is `/health/ready`. Authenticated OpenAPI
documents are `/openapi/operator.json` and `/openapi/agent.json`. The Agent
contract remains provisional until the work-loop recovery conversation and
cross-language Agent fixtures are implemented.

The [hardening guide](operations-hardening.md) describes named Operators,
metrics, cleanup, and listener validation. A manual
[backup/restore tool](backup-restore.md) is available. Backup scheduling,
retention periods, issuing-key rotation, release signing, and measured load
budgets remain release work. See [implementation status](../implementation-status.md).
