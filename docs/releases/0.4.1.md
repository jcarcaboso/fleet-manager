# Server 0.4.1

The dashboard now has a **Sync repository** button. It fetches and validates the
configured Git source, then publishes changed assignments. The result distinguishes
publication, unchanged source, an active scan, missing configuration, and failures.
Running Agents fetch assignments on their next poll, normally within 60 seconds.

The existing Operator command `fleet source rescan` performs the same operation.
The CLI and Agent remain at 0.4.0 and work with this server release.

## Upgrade

Set `FLEET_IMAGE=skorcius/fleet-manager:0.4.1` in your homelab `.env`, then run:

```sh
docker compose pull
docker compose up -d
```

The image includes the dashboard and targets Linux amd64. Preserve your existing
configuration and volumes. No new database migration is required.

## Validation

All 65 server tests passed, including dashboard session, origin, and CSRF checks
for repository sync. JavaScript outcome and duplicate-click checks, formatting,
and documentation link checks passed.
