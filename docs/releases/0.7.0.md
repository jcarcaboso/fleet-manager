# Fleet Manager 0.7.0

This minor release adds Claude Code connections to Fleet's CLIProxy integration.
Codex and OpenCode connections continue to work as before.

## Claude Code configuration

Add Claude under a Node's `targets` in a `fleet/v2` manifest:

```yaml
ai-clients:
  claude:
    mode: cliproxy
```

Use the existing Workspace `cliproxy.base-url` and Server
`Fleet:CliProxyApiKey` configuration. An optional `model` pins the default to an
advertised identifier. Without it, Fleet keeps the locally selected model when
available, otherwise selects the first advertised model.

The Agent configures `~/.claude/settings.json`, managing only `model`,
`env.ANTHROPIC_BASE_URL`, and `apiKeyHelper`. The helper reads the private
credential file, so Fleet does not place the proxy key in Claude settings.
Claude's URL uses the proxy root because the client appends `/v1/messages`.
Unrelated settings and native login files remain untouched.

Remove conflicting `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_API_KEY`, and
`ANTHROPIC_MODEL` overrides before enabling CLIProxy. Fleet rejects conflicting
entries in the settings environment rather than recording their credentials.
Switching to `mode: native`, or removing the managed entry, restores the original
Fleet-owned settings. Changes to owned connection fields outside Fleet produce
an ownership error rather than being overwritten.

## Upgrade

Upgrade both the Server and selected Agents to 0.7.0 before publishing
`ai-clients.claude` entries. Preserve existing Agent state and credentials.
No re-enrollment or database migration is required.

See the [CLIProxyAPI operations guide](../technical-design/cliproxy-operations.md)
and [example manifest](../../examples/source/fleet-cliproxy.yml).

## Verification

Local verification passed 113 Server tests and 40 Agent tests, Agent Clippy,
Rust formatting, and documentation-link checks. Regression coverage includes
Claude target publication, native restoration after target removal, automatic
model selection, conflicting settings, preservation of unrelated settings and
native credentials, and creation and removal of the managed settings file.

Live Claude inference and release archives have not been verified locally.
