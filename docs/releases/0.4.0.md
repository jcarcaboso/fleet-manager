# Fleet Manager 0.4.0

The dashboard now supports revoking and permanently removing Nodes.

- **Revoke** blocks every certificate belonging to the Node while retaining its
  server record and alias.
- **Remove** requires typing the exact alias, then deletes the Node, credentials,
  assignments, attempts, and enrollment delivery records. The alias becomes
  available again. Audit events and shared rollout/bundle data remain.

Neither action erases files on the machine. Stop its Agent and remove the
`fleet.yml` entry unless you intend to enroll a replacement. Removal also works
on an active Node; a separate revoke action is not required.

## Upgrade the server

Set `FLEET_IMAGE=skorcius/fleet-manager:0.4.0` in the homelab `.env`, then run:

```sh
docker compose pull
docker compose up -d --force-recreate --wait
```

The dashboard is part of the amd64 server image. No new database migration is
needed when upgrading from 0.3.0. Keep your existing secrets, Operator token,
Agent state, and Docker volumes. Back up PostgreSQL before upgrading.

Upgrades from 0.2.0 also need the current Compose file and the enrollment-link
migration introduced in 0.3.0. Compose runs pending migrations automatically.

## Clients and Homebrew

Client binaries carry version 0.4.0 for a consistent release. Existing enrolled
Agents remain compatible and do not need to enroll again. This release does not
add an immediate-sync command or change the single-Agent state lock.

```sh
brew services stop jcarcaboso/fleet/fleet-agent
brew update
brew upgrade jcarcaboso/fleet/fleet-agent jcarcaboso/fleet/fleet
brew services start jcarcaboso/fleet/fleet-agent
```

Only include packages you have installed. Update one Node and verify contact
and sync before updating the rest. Homebrew installs prebuilt Linux amd64 and
macOS Intel/Apple silicon binaries, with formulas updated after release tests.
