# Fleet Manager 0.6.5

This release fixes Codex CLIProxy authentication on Nodes without `/bin/cat` and
restores native Codex and OpenCode connections when their proxy assignments are
removed. It includes the CLIProxy model-family selection added after 0.6.3.

## Upgrade

Set `FLEET_IMAGE=skorcius/fleet-manager:0.6.5` in the deployment's `.env`, then
run `docker compose pull` and `docker compose up -d --force-recreate --wait`.
Upgrade `fleet-agent` to 0.6.5 on each Node and restart its service so Codex
configuration is regenerated. Keep the existing Node state and client login
files. Both the Server and Agent must be updated before removing proxy-managed
clients from desired state.

## Verification

The disposable Server and Agent smoke test covered CLIProxy configuration,
`native` mode, removal of both AI-client entries, and preservation of client
auth files. Codex also returned a live response through CLIProxy with the
corrected auth command. Client native login was not exercised with live accounts.
