# Fleet Manager 0.5.1

This hotfix restores optional source roots. A repository may omit `agents/`
when it does not manage AI-client instruction files, omit `skills/` when it has
no Skills, or omit both. An explicit reference to an unknown agent source or
Skill group still rejects the source revision.

Agent-file clearing now preserves each destination as an empty file. Omitting
`targets.agents` leaves every client untouched, `agents: []` clears all known
client files, and a nonempty list deploys only to its selected clients.

Rejected source scans now write each bounded validation diagnostic to the
Server log with its code, path, and message. Git failure messages remain hidden
because they may contain remote stderr.

## Upgrade

Set `FLEET_IMAGE=skorcius/fleet-manager:0.5.1` in the homelab `.env`, then run:

```sh
docker compose pull
docker compose up -d --force-recreate --wait
```

No new database migration is required. Existing 0.5.0 clients remain protocol
compatible, though the tagged release also publishes matching 0.5.1 client
artifacts.
