# Fleet Manager 0.15.2

Images: `skorcius/fleet-manager:0.15.2` for the Server and
`skorcius/fleet-manager:dashboard-0.15.2` for the dashboard, Linux amd64.

This release adds Google Antigravity as a fourth supported AI client and bumps
the Rust `url` crate to 2.5.9 to clear RUSTSEC-2026-0592. There is no database
migration and no change to enrollment, ownership receipts, or service
definitions. Existing Agents keep working unchanged; the new client is
capability-gated.

## Google Antigravity support

The Agent registers Antigravity as a fourth AI client/tool. Its adapter writes
`~/.gemini/config/config.json`, and a Claude-like duplicate
`skills/antigravity` Target publishes to `~/.gemini/config/skills` with an
`excludeAntigravity` flag.

Model routing splits the `gemini-*` models into their own group that defaults
to Antigravity only. Nodes running an earlier Agent keep a three-key routing
catalog where Gemini models fall back to the other route, so mixed fleets are
safe: the new Targets are capability-gated on poll
(`skills/antigravity`, `ai-client/antigravity`, `agent-file/antigravity`) and
older Agents simply never receive them.

The dashboard shows the fourth client and its routing group.

## url 2.5.9 (RUSTSEC-2026-0592)

`clients/Cargo.lock` pinned `url` 2.5.8. The advisory DB gained
RUSTSEC-2026-0592 (stack overflow in `Url::origin` on nested `blob:` URLs) on
2026-11-20, so the CI dependency audit fails below 2.5.9. The lockfile moves
`url` to 2.5.9 and its transitive `form_urlencoded` to 1.2.3; both are
patch-level updates with no code changes.

## Upgrade

1. Once the release is published, upgrade the Server and dashboard together.
   Set `FLEET_IMAGE=skorcius/fleet-manager:0.15.2` and
   `FLEET_DASHBOARD_IMAGE=skorcius/fleet-manager:dashboard-0.15.2` in `.env`,
   then run `docker compose pull` and `docker compose up -d --force-recreate --wait`.
2. Update Agents from the dashboard, or with `fleet nodes update <node>` or
   `fleet nodes update --all-outdated`. Updated Agents gain the Antigravity
   client and Targets on their next poll. Nodes that never use Gemini models
   need no action.

## Verification

- Agent tests cover the Antigravity adapter, the four-key routing catalog, and
  the legacy three-key fallback for older Agents; Server tests cover the
  capability gating and Antigravity Target publication.
- `cargo audit`, clippy with `-D warnings`, and the full locked workspace test
  suite pass with `url` 2.5.9.
- CI must pass on the PR before merge and on the release commit before
  tagging. Image publication, release tagging, signed archives, Homebrew
  updates, and verification of published artifacts happen after the release PR
  is merged. macOS behavior is not verified locally.
