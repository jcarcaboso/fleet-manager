# Fleet Manager 0.5.0

Fleet can now manage AI-client instruction files on each Node. A source stored
at `agents/<source>/AGENTS.md` can target Codex, OpenCode, Claude Code, or any
subset of those clients. Fleet writes the client-specific destination and uses
`CLAUDE.md` for Claude Code.

Skill groups now come from `skills/<group>/<skill>/`. Remove the top-level
`groups` catalog from `fleet.yml`. An omitted or empty per-Node `groups` array
selects every discovered group, while a nonempty array selects a subset and
sets duplicate-Skill precedence. Accepted source revisions must contain at
least one valid Skill and one valid agent instruction source.

## Upgrade

Upgrade `fleet-agent` to 0.5.0 before adding `targets.agents` entries. Existing
Skill-only assignments remain usable while agent instruction sources are not
assigned.

Move the old `groups/<group>/<skill>/` tree to
`skills/<group>/<skill>/`, remove the top-level `groups` field, and add at least
one `agents/<source>/AGENTS.md` file in the same source commit. The Server
rejects partial migrations and keeps the last accepted desired state active.

Set `FLEET_IMAGE=skorcius/fleet-manager:0.5.0` in the homelab `.env`, then run:

```sh
docker compose pull
docker compose up -d --force-recreate --wait
```

Compose applies the Managed-file database migration before starting the Server.
Preserve the existing PostgreSQL data, Server configuration, TLS files, SSH
configuration, Operator token, and Agent state.

## Validation

The release passed all 79 Server tests and all 50 Rust tests. .NET and Rust
formatting, Clippy with warnings denied, Python syntax checks, and documentation
link checks also passed.
